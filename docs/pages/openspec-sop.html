OpenSpec SOP

Imported projects expose OpenSpec through a local helper command and the AI assistant's own command or skill surface.

Terminal

./scripts/openspec.sh help
./scripts/openspec.sh brownfield
./scripts/openspec.sh validate
./scripts/openspec.sh list
./scripts/openspec.sh show <change-or-spec>

The helper delegates to the official openspec CLI when it is installed. It does not vendor or install the CLI.

AI Assistant

OpenSpec workflow commands are typed in the AI assistant chat, not the terminal.

  • Claude Code: /opsx:explore, /opsx:propose, /opsx:apply, /opsx:archive
  • Cursor/Windsurf/Copilot IDE: /opsx-explore, /opsx-propose, /opsx-apply, /opsx-archive
  • Codex: use the installed OpenSpec skills, typically $openspec-explore, $openspec-propose, $openspec-apply-change, $openspec-archive

Brownfield Workflow

  1. Do not document the whole existing app up front.
  2. Pick one small real change.
  3. Create a proposal, spec delta, design notes, and task list.
  4. Review before implementation.
  5. Implement from the approved tasks.
  6. Validate and archive accepted requirements into openspec/specs/.
