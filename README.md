# AI Development Guardrails

Reusable guardrails for AI-assisted software development.

This repo defines a lightweight operating model for projects that use AI coding agents:

- Write or update a spec before non-trivial implementation.
- Review proposal, design, and tasks before code changes.
- Keep documentation concise and useful.
- Reuse existing patterns before adding new abstractions.
- Validate changes with tests, checks, or documented manual verification.

## What Is Included

- `AGENTS.md`: default rules for AI coding agents.
- `openspec/`: OpenSpec-style specs and change folders.
- `docs/`: plain HTML documentation pages.
- `templates/`: reusable proposal, review, and deployment templates.
- `.github/workflows/`: minimal documentation validation workflow.

## How To Use

Copy or import the relevant files into an application repo.

For feature work:

1. Create a change under `openspec/changes/<change-name>/`.
2. Write the proposal, spec delta, design notes, and tasks.
3. Review the artifacts before implementation.
4. Implement the tasks.
5. Archive the change into `openspec/specs/` when complete.

## Documentation Rule

Documentation should be short, structured, and intentional. Avoid noisy autogenerated prose, decorative styling, and unrelated operational detail.
